#Intended User(s) of Code and/or Data of Repo
The intended users of this git repo are the student author (myself), the instructor and any fellow student collaborators in the CSE 3000 Fall 2026 course. The code and data are used for completing assignments and learning objectives / goals. 
The repository can be publicly viewed through GitHub but should not be edited without permission. 


#Security Threats Risk Assessment an assessment of risk of security threats (i.e., relevant concerns if the code or data fell into the wrong hands)
The security risk of this repo is low to moderate. Since this is a publicly viewable repository, secrets or sensitive data should not be published in this repo. There is no highly sensitive data like passwords, personal or financial data. However the data within assignments should not be modified by unauthorized agents to ensure that students' work is protected and not altered so they receive credit and proper evaluation for the work they complete. 
Some concerns if the code or data fell into the wrong hands includes attackers modifying the code to introduce malicious behaviors which could be harmful to users to copy or download the repo. An attacker altering the code or data could affect the evaluation of student assessments. 


#Steps to Secure Repo steps you've taken to secure your repo (e.g., a CODEOWNERS file, rulesets for pull requests, etc.), or a statement of why that is not necessary.
Steps to secure this repo include the following: 
1. No committing of secrets, passwords, authentication tokens, personal or financial data
2. A .gitignore file will be used to ignore local environment and configuration files to prevent them from being committed 
3. A CODEOWNERS file that lists the contributors to the repo 
4. Review all changes before they are pushed to 'main'
